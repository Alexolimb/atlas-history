# Как устроены главы пути

Одна глава — один файл `content/<язык>/e<эпоха>/c<номер>.md`.
Например `content/ru/e04/c02.md` — вторая глава четвёртой эпохи по-русски.

При сборке (`npm run content`) все файлы превращаются в один
`src/generated/course.json`, а каждый факт из раздела `facts`
сверяется с Wikidata. Не сошлось — сборка падает.

## Шапка файла

```yaml
---
id: e04c02                  # совпадает с путём файла
epoch: 4                    # номер эпохи, 1..12
order: 2                    # порядок главы внутри эпохи
title: Римская республика
subtitle: Как город стал хозяином Средиземного моря
years: [-509, -27]          # о чём глава, для ленты времени
globe:                      # куда смотреть на глобусе
  year: -100
  focus: Q1747689           # какую страну подсветить (Q-номер)
cards: [Q1048, Q1747689]    # карточки справочника под текстом
facts:                      # ЧТО ПРОВЕРЯЕТСЯ ПО WIKIDATA
  - { q: Q1048, prop: birth, year: -100 }
  - { q: Q1747689, prop: start, year: -753 }
quiz:
  - type: date              # «в каком году»
    q: Q1048
    prop: death
    text: В каком году убили Юлия Цезаря?
  - type: order             # «расставьте по порядку»
    text: Что было раньше?
    items: [Q1048, Q517]
  - type: who               # «кто это»
    q: Q1048
    text: Кто перешёл Рубикон и стал пожизненным диктатором?
---
```

## Правила

1. **Ни одной даты и ни одного имени в тексте, которых нет в `facts`.**
   Проверка сверяет `facts` с Wikidata; всё, что мимо неё, — слово на веру.
2. `facts` пишутся так: `q` — Q-номер, `prop` — что проверяем
   (`birth`, `death`, `start`, `end`), `year` — ожидаемый год.
3. Текст — простыми словами, без жаргона. Термин ввёл — тут же расшифровал.
4. Длина 700–1000 слов: это 5–8 минут чтения.
5. В конце главы — крючок «почему это важно сегодня».
6. Русская и английская версии описывают одно и то же и имеют одинаковую шапку.

## Что проверяет `npm run content`

- шапка на месте и полная;
- `id` совпадает с путём файла;
- каждая глава есть и по-русски, и по-английски, и шапки совпадают;
- все `Q`-номера существуют;
- **каждый факт сверен с Wikidata** — иначе сборка падает;
- вопросы викторины опираются только на проверенные факты.
