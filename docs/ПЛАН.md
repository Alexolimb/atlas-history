# ATLAS — план стройки (утверждён 05.09.2026)

> Это единственный источник правды по проекту. Новый чат = открыть этот файл + `ЖУРНАЛ.md` и продолжить с той части, где стоит ⬜.
> Правило стройки: идти строго по частям, ничего сверх плана, без вопросов Алексу (кроме §0 CLAUDE.md). Каждая часть заканчивается воротами `npm run check` + записью в ЖУРНАЛ + git push + копией на F:.

## 1. Что строим (утверждено допросом)

**Atlas** — приложение, в котором любой человек изучает всю историю мира: все страны и империи от −10000 до 2026, правители, династии, древа семей, войны и события, знаменитые личности. Толстый красивый справочник + путь по эпохам + игровой слой.

| Решение | Выбор Алекса |
|---|---|
| Устройства | Веб-приложение (PWA): один код на Android, iPhone, ноутбук, планшет. Ярлык на столе и на телефоне. Потом обёртка Capacitor → Play Market, подписка/оплата в приложении (НЕ в v1) |
| Факты | Wikidata (структура: даты, родство, должности) + Wikipedia (тексты, картинки) + проверенные источники ссылками. У каждой карточки кнопка «Источник». Ничего из головы модели |
| Офлайн | Ядро внутри (путь, ~500 ключевых сущностей, границы), глубина онлайн из Wikidata/Wikipedia с кэшем на устройстве |
| Формат | Справочник открыт ВЕСЬ и ВСЕГДА + игровой слой сверху. Ничего не заперто |
| Имя | **Atlas**. Папка `C:\dev\atlas`, репозиторий `Alexolimb/atlas-history` (публичный — GitHub Pages бесплатен только для публичных), адрес `https://alexolimb.github.io/atlas-history/` |
| Хостинг | GitHub Pages, выкладка сама при push в `main` |
| ИИ-гид | Через n8n (ключ на сервере), бесплатная модель Gemini. Роль — гид по открытой карточке и прогрессу, не «спроси что угодно» |
| Музыка | 3–5 лоуфай-треков с Pixabay внутри, по умолчанию ВЫКЛ. Звук перелистывания. Лицензии в `licenses/` |
| Вид | Тёмный «музей»: глубокий тёмно-синий, золото, слоновая кость, засечки в заголовках. Главный экран — 3D-глобус с ползунком времени −10000…2026. Светлая тема в настройках. 3D только на глобусе, слабый телефон → плоская карта |
| Путь | 12 эпох × 3–4 главы (~42). Глава = рассказ 5–8 минут + карточки справочника + момент на глобусе + проверка |
| Игра | Опыт, уровни, серия дней, достижения · проверки после главы (дата / порядок событий / кто это) · интервальное повторение · «тайна дня» + «угадай год по глобусу» |
| Прогресс | На устройстве (IndexedDB) + файл переноса «Сохранить / Загрузить». Учёток нет |
| Языки | RU + EN полностью (включая рассказы глав). Ещё 28 — меню, кнопки, весь справочник (из Wikidata/Wikipedia на этом языке); рассказы глав на них по-английски с пометкой |
| Настройки | язык · тема · музыка вкл/громкость · звук страниц · размер текста · меньше движения · 3D вкл/выкл · сброс/перенос прогресса |
| Тест | Ноутбук Windows + Android-телефон (Chrome) |

## 2. Архитектура

```
Браузер / PWA (React 18 + TypeScript + Vite)
 ├─ Экраны: Глобус · Путь · Справочник · Повторение · Профиль · Настройки
 ├─ Данные: core-пакет (JSON, внутри) → IndexedDB-кэш → онлайн Wikidata/Wikipedia
 ├─ Service Worker (vite-plugin-pwa): офлайн оболочка + кэш карточек и картинок
 └─ ИИ-гид → https://n8n…/webhook/atlas-guide (сервер Hetzner) → Gemini free

Сборка (ноутбук, Node 24): scripts/data/* → Wikidata SPARQL/API → public/data/core/*.json
                            content/{ru,en}/**/*.md → src/generated/course.json (+ fact-check по Wikidata)
                            границы: historical-basemaps → упрощение (mapshaper) → public/data/borders/*.json
```

| Слой | Чем | Почему |
|---|---|---|
| Каркас | Vite 6 + React 18 + TypeScript 5 | как NEXUS, обкатано |
| PWA | vite-plugin-pwa (Workbox) | офлайн + «Установить» на Android и Windows |
| Маршруты | react-router 7, BrowserRouter + `404.html` = копия `index.html` (GitHub Pages) | обычные ссылки, «назад» работает как в браузере |
| Состояние | zustand + persist в IndexedDB (idb-keyval) | просто, без сервера |
| Кэш сущностей | Dexie (IndexedDB) | тысячи карточек, быстрый поиск офлайн |
| Глобус | react-globe.gl (MIT) + полигоны границ по снимкам | готовый глобус, тап по стране |
| Плоская карта (запас) | d3-geo на canvas | слабые телефоны, «меньше движения» |
| Древа | d3-hierarchy / своя раскладка + svg | семейные древа раскрываются по клику |
| Анимации | framer-motion | плавно, отключаемо |
| Языки UI | i18next, 30 JSON | стандарт |
| Контент глав | Markdown с frontmatter → JSON при сборке | быстро писать, проверять кодом |
| Аудио | HTML Audio + свой мини-плеер | без зависимостей |
| Тесты | vitest (данные, квизы, SRS, проверка фактов) + `npm run check` (typecheck + tests + валидация данных + бюджет размера) | ворота каждой части |
| Выкладка | GitHub Actions → Pages | ноль ручных шагов |

**Модель данных (ядро):** `Entity {id: Q-номер, type: state|person|event|dynasty|place, labels{lang}, descr{lang}, start, end, coords, image, wiki{lang: title}, claims: {P35 правители…, P22/P25/P26/P40 родство, P17 страна…}, sources[]}`. Всё, что показывается, имеет `id` Wikidata и ссылку — это и есть защита от выдумки.

**Границы для глобуса:** `aourednik/historical-basemaps` — 54 снимка мира (−123000 … 2010), GeoJSON, лицензия GPL-3 (данные лежат отдельно в `public/data/borders/` с LICENSE и упоминанием автора на экране «Источники»; код приложения от них не зависит). Ползунок берёт ближайший снимок. Точность у автора помечена полем BORDERPRECISION — показываем честно («границы приблизительные»). Запасной вариант, если лицензия помешает Play Market: OpenHistoricalMap (ODbL).

**Лицензии текстов/картинок:** Wikipedia — CC BY-SA 4.0 (подпись на карточке), Wikidata — CC0, Commons-картинки — подпись автора/лицензии из API. Экран «Источники и лицензии» обязателен.

**Шаблон главы** (`content/ru/e05/c02.md`): frontmatter (`id, epoch, title, years, globe:{year, lat, lng, zoom}, cards:[Q…], facts:[{claim, q, prop, value}], quiz:[…]`) + рассказ 700–1000 слов простым языком, с крючком «почему это важно сегодня». Скрипт `check:facts` сверяет каждую дату/имя из `facts` с Wikidata — глава не собирается, если расходится.

## 5. Правила стройки
1. Ни одного факта в приложении без Q-номера Wikidata и ссылки. Рассказ главы — только по `facts`, которые прошли `check:facts`.
2. Бюджеты: первая загрузка ≤ 1,5 МБ JS, core-пакет ≤ 15 МБ, снимок границ ≤ 250 КБ, музыка ≤ 12 МБ суммарно.
3. Каждая часть: `npm run check` зелёный → запись в `ЖУРНАЛ.md` (сделали · пробовали · дальше) → `git push` → `F:\_BACKUPS\code\atlas\<дата>` (не больше двух копий).
4. Ничего не удалять и не переписывать без копии. `robocopy /E`, никогда `/MIR`.
5. Не расширять план. Идея «а ещё бы…» → строка в раздел «Долгий ящик» ниже, не в код.
6. Секреты (ключи n8n, Gemini) — только на сервере и в `Brain\Claud\`. В репозитории — только адрес вебхука.

## 6. Риски и запасные ходы
- Wikidata SPARQL медленный (2026): пайплайн с повторами, сырые ответы сохраняются в `data-raw/` (в git не идут, копия на F:), запросы дробить по 200 сущностей.
- GPL-3 на границах: данные отдельным пакетом с лицензией; если понадобится для Play Market — заменить на OpenHistoricalMap.
- iPhone Safari: 3D и автозапуск звука капризны — проверка отдельно, после Android.
- Публичный вебхук гида: лимит запросов в n8n + короткий ответ, чтобы бесплатный ключ не выжгли.
