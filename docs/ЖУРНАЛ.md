## 05.09.2026 · ✅ Часть 1 — данные из Wikidata

**Сделали**
- Пайплайн `scripts/data/`: отбор Q-номеров запросами по объективному признаку (число разделов Википедии), полные данные через wbgetentities, разбор в свою форму, запись `public/data/core/`.
- Ядро: 835 карточек — 340 государств (все члены ООН + исчезнувшие империи), 381 человек, 77 событий, 37 династий. 9800 связей. Имена и описания на 30 языках, 7531 имя на русском.
- Догрузка из сети по требованию (`src/lib/wikidata.ts`) + кэш на устройстве с сроком годности (`src/lib/cache.ts`). Тексты статей и лицензии картинок (`src/lib/wikipedia.ts`).
- Ворота `npm run data:check` — 20 проверок, включая опорные факты: Цезарь −100…−44, Александр −356…−323, Наполеон 1769…1821, СССР 1922…1991, Древний Рим −753…476.
- Живая проверка источников `npm run data:smoke` (в ворота НЕ входит: профилактика у Wikipedia не должна ронять сборку).

**Пробовали (грабли)**
1. **Кириллица в заголовке HTTP роняет каждый запрос.** В User-Agent было русское описание — `fetch` падал ещё до выхода в сеть, с сообщением про ByteString. Заголовки умеют только латиницу.
2. **Широкий запрос SPARQL не досчитывается.** «Все люди с должностью» и `VALUES` из девяти занятий обрывали соединение. Лечение: один запрос — один узкий класс; правители берутся не запросом, а из свойств самих государств.
3. **Ловушка `mul`.** С 2024 года Wikidata хранит имена, одинаковые во всех языках латиницы, ОДИН раз под кодом `mul` и удаляет их из английского. Кто просит только `en`, не находит имени у Эйнштейна, Дарвина, Трампа — и не замечает: ошибки нет, просто пусто. Просим `mul` и подставляем его.
4. **Ключ кэша не учитывал набор языков** — после добавления `mul` старые ответы читались бы дальше и вернули бы ту же пустоту. Добавлена метка версии в ключ.
5. **Известность упиралась в 30.** Считали число разделов Википедии с фильтром по нашим 30 языкам — счётчик всегда упирался в 30 и переставал различать. Настоящий счёт берётся отдельным запросом без фильтра.
6. **Заголовки статей на 30 языках раздували общий файл вдвое.** Перенесены в файлы имён по языкам: приложение грузит один язык, а не тридцать.

## 05.09.2026 · ✅ Часть 3 — глобус с ползунком времени

**Сделали**
- 52 карты мира от −10000 до 2010 (`aourednik/historical-basemaps`, GPL-3). Каждая прорежена своим алгоритмом Рамера — Дугласа — Пекера: сырые файлы по 3–20 МБ ужаты до 8–144 КБ, форма стран узнаваема. Всего 3,3 МБ вместо сотен.
- Объёмный глобус (`react-globe.gl`) с золотой атмосферой. Цвет страны выводится из её имени, поэтому один и тот же цвет держится во все годы — двигая ползунок, видно, как ИМЕННО ЭТА страна росла и сжималась.
- Плоская карта на обычном SVG как запасной вид: без библиотек, работает на слабых устройствах.
- Ползунок ходит по срезам карт, а не по годам: каждое положение — настоящая карта, а не выдуманная середина. Плюс быстрые метки: Античность, Рим, Средние века, Открытия, Империи, Войны, Сегодня.
- Касание страны → её карточка. Связка «подпись на карте → Q-номер» строится отдельным скриптом.
- Код глобуса (внутри three.js, 1,9 МБ) грузится отдельным куском только при заходе на главный экран. Пока он едет, показывается плоская карта — не чёрный прямоугольник с надписью «загружаю».
- На слабом устройстве (мало памяти, мало ядер, экономия трафика, медленная сеть) объёмный глобус по умолчанию выключен. Переключатель в настройках остаётся.

**Как связывали страны с карточками (и почему так осторожно)**
Открыть по нажатию на Русь карточку Румынии хуже, чем не открыть ничего: человек прочитает неправду и не поймёт этого. Поэтому связываем только при точном совпадении имени — сначала с английскими именами ядра, потом с именами и прозвищами в Wikidata, и всегда отсекая заведомо не-страны по описанию («порода утки», «фильм», «песня»). Связалось 1401 подпись из 2298. По картам: 2010 год — 98%, 1914 — 95%, 1500 — 69%, 500 — 59%, −1 — 52%. Несвязанное — это в основном сборные подписи вроде «Islamic city-states» и «Mossi States», у которых одной карточки и не должно быть. Такая страна на глобусе всё равно видна и подписана, просто не открывается.

**Пробовали (грабли)**
1. **Глобус раздувал страницу до бесконечности.** Наблюдатель мерил контейнер → canvas рос → контейнер рос → canvas рос ещё. Страница уезжала вбок на телефоне. Лечение: размер задаёт только внешний блок через `aspect-ratio`, а глобус лежит внутри absolute-слоем и раздвинуть родителя не может. Плюс округление ширины вниз — дробные значения сами по себе гоняют пересчёт по кругу.
2. **«Франция в подчинении: Франция».** У независимых стран поле «в подчинении» повторяет собственное имя. Держим его, только если там ДРУГАЯ страна.
3. **Первая проверка связей искала «Muscovy», а на карте написано «Tsardom of Muscovy».** Проверять надо по тем именам, что реально есть в данных, а не по тем, что кажутся.
4. **Прозвища.** Строгое совпадение с основным именем оставляло без карточек СССР («USSR») и Московское царство. Теперь принимаем и совпадение с прозвищем — но только если Wikidata сама сказала, что попала именно в прозвище. Связность выросла с 55% до 61%.
5. **Бюджет размера считал не то.** Он складывал весь JS, включая глобус, который грузится по требованию, — и запрещал сборку. Переписан: первая загрузка берётся из `index.html` (теги script и modulepreload), остальное считается отдельно. Первая загрузка — 295 КБ.
6. `.at()` у массивов требует библиотеки ES2022 в настройках TypeScript; для импорта `.mjs` в тест нужен файл описания типов с расширением `.d.mts`, а не `.d.ts`.
