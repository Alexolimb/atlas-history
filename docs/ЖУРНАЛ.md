- Прогресс в IndexedDB + перенос файлом «Сохранить / Загрузить», формат версионирован, чужой файл отвергается.
- PWA: манифест, service worker, офлайн проверен вживую — сервер выключен, приложение открылось и глубокая ссылка тоже.
- Иконки рисуются кодом (`npm run icons`): PNG 192/512/maskable, apple-touch, favicon.svg, atlas.ico для ярлыка. Ни одного бинарника руками.
- Ярлык на рабочем столе: `scripts/yarlyk.ps1` → Chrome в режиме отдельного окна.
- Выкладка: GitHub Actions → Pages, с воротами «сборка не пустая» (index/404/манифест/sw и минимум файлов).
- Ворота `npm run check`: типы + 28 тестов + сборка + бюджет размера. Сборка 320 КБ, JS 291 КБ при бюджете 1536 КБ.

**Пробовали (грабли)**
1. `defineConfig` из `vitest/config` в `vite.config.ts` роняет сборку: у vitest своя вложенная копия vite, типы плагинов двух копий не сходятся. Лечение — отдельный `vitest.config.ts` без плагинов.
2. `PageHead` берёт ключ `${ns}.sub`; забытый ключ не падает, а печатает на странице «settings.sub». Нашлось глазами на скриншоте. Заведён `tests/screens.test.ts` — он тут же поймал вторую такую же дырку (`sources.sub`).
3. Переключатель из трёх вариантов на флексе сваливался во вторую строку на 375 px. Переведён на сетку `1fr 1fr 1fr`.
4. Подписи в профиле были захардкожены по-русски мимо i18n — переведены на ключи `profile.stats.*`.
5. `.claude/launch.json` читается из корня `C:\`, а не из папки проекта — конфигурации `atlas-dev` и `atlas-prod` добавлены туда.
6. Не вешаемся на системный `prefers-reduced-motion`: у Алекса анимации Windows выключены, и приложение молча стало бы неподвижным. Слушаем только настройку внутри приложения.
