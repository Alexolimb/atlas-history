# Музыка приложения

Сюда кладутся фоновые треки. **Пока папка пуста, приложение играет свой
собственный спокойный фон, собранный прямо в браузере** — он весит ноль байт
и работает офлайн. Настройка «Фоновая музыка» работает в любом случае.

## Как положить свои треки (5 минут)

1. Зайти на **https://pixabay.com/music/** и выбрать 3–5 спокойных треков
   (поиск: `lofi`, `ambient`, `study`). Лицензия Pixabay разрешает
   использовать их в приложении, в том числе платном, и не требует подписи.
2. Нажать «Download» у каждого. Файлы скачаются как `.mp3`.
3. Положить их в эту папку — `public/audio/`.
4. Создать рядом файл **`tracks.json`** вот такого вида:

```json
{
  "tracks": [
    {
      "file": "lofi-study.mp3",
      "title": "Lofi Study",
      "author": "FASSounds",
      "licence": "Pixabay Content License",
      "source": "https://pixabay.com/music/beats-lofi-study-112191/"
    }
  ]
}
```

5. Пересобрать: `npm run check`. Приложение подхватит треки само и начнёт
   играть их по кругу вместо своего фона.

## Бюджет

Суммарно не больше **12 МБ** — иначе ворота размера (`npm run budget`)
не пропустят сборку. Три-четыре трека по 3 МБ укладываются свободно.

## Почему они не скачаны заранее

Pixabay отдаёт ссылки на сами файлы только своим скриптом в браузере,
поэтому скачать их из сборочного скрипта не получается. Вписывать вместо них
случайные ссылки с других сайтов — значит рисковать чужой лицензией
в приложении, которое может стать платным. Поэтому: работающий свой фон
сразу и понятная инструкция на пять минут для настоящих треков.
