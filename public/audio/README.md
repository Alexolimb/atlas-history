# Музыка приложения

Здесь лежит фоновая музыка. Сейчас в папке **четыре трека Кевина Маклауда**
(incompetech.com), спокойные фортепиано и синтезаторы: `deliberate-thought`,
`daybreak`, `aretes`, `blue-feather`. Приложение играет их по кругу, но
**только когда человек сам включил переключатель** — по умолчанию тишина.

## Лицензия и подпись

Все четыре — **Creative Commons Attribution 4.0** (CC BY 4.0). Это разрешает
использование в приложении, в том числе платном, при одном условии: указать
автора. Подпись стоит на экране «Источники» и в `tracks.json`.

Формат подписи, которого просит автор:

> Music: «Название» by Kevin MacLeod (incompetech.com)
> Licensed under Creative Commons: By Attribution 4.0
> https://creativecommons.org/licenses/by/4.0/

Условия проверены на https://incompetech.com/music/royalty-free/faq.html

## Как файлы попали сюда

Каталог автора лежит открыто: `https://incompetech.com/music/royalty-free/pieces.json`
— 1442 пьесы с названиями, длительностью и настроением. Отобраны те, у кого
в поле `feel` стоит «Calming/Relaxed». Исходники скачаны по адресу
`https://incompetech.com/music/royalty-free/mp3-royaltyfree/<Название>.mp3`
(там 320 кбит/с стерео, по 7–11 МБ) и пережаты в моно 80 кбит/с:

```
ffmpeg -i "Название.mp3" -ac 1 -ar 44100 -b:a 80k -map_metadata -1 название.mp3
```

Итог — 10,2 МБ на четыре трека против 36 МБ исходников. Для фона, который
играет тихо и в основном на телефонных динамиках, разницы на слух нет.

## Если захочется заменить

1. Скачать своё (Pixabay, incompetech, любой источник с понятной лицензией).
2. Положить `.mp3` сюда, пережать той же командой.
3. Поправить `tracks.json`: `file`, `title`, `author`, `licence`, `source`.
4. Если лицензия другая — поправить строку на экране «Источники»
   (`src/routes/SourcesScreen.tsx`).
5. `npm run check`.

**Про Pixabay:** их музыку скачать из скрипта нельзя — ссылки на файлы
отдаёт только их собственный код в браузере. Поэтому взят каталог, который
доступен машине и у которого лицензия написана самим автором.

## Бюджет

Суммарно не больше **12 МБ** — иначе ворота размера (`npm run budget`)
не пропустят сборку. Сейчас занято 10,2 МБ.

## Если папку опустошить

Приложение не сломается: при отсутствии `tracks.json` оно играет
собственный фон, собранный прямо в браузере. Он весит ноль байт
и работает офлайн с первой секунды.
