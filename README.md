# Atlas — вся история мира в одном приложении

Справочник всех стран, империй, правителей и семейных древ от −10000 до наших дней,
путь по двенадцати эпохам и игровой слой. Открывается на телефоне, планшете и компьютере,
работает офлайн. Ни одного выдуманного факта: всё приходит из Wikidata и Wikipedia со ссылкой на источник.

**Живой адрес:** https://alexolimb.github.io/atlas-history/

## Как запустить у себя

```bash
npm install
npm run dev      # http://localhost:5183/atlas-history/
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Живая сборка для разработки |
| `npm run build` | Готовая сборка в `dist/` |
| `npm run preview` | Посмотреть готовую сборку как на боевом адресе |
| `npm run icons` | Пересобрать иконки приложения (PNG рисуются кодом) |
| `npm run test` | Тесты |
| `npm run typecheck` | Проверка типов |
| `npm run budget` | Ворота размера сборки |
| **`npm run check`** | **Всё сразу — эти ворота обязаны быть зелёными перед каждым `git push`** |

## Что где лежит

```
docs/ПЛАН.md          единственный источник правды: решения, части, порядок
docs/ЖУРНАЛ.md        что сделано в каждой сессии
docs/УСТАНОВКА.md     как поставить приложение на телефон и на компьютер
src/styles/tokens.css вся палитра и типографика; в компонентах только var(--…)
src/i18n/             30 языков: список в languages.ts, тексты в locales/
src/store/            настройки и прогресс (IndexedDB, без учётных записей)
src/routes/           экраны
scripts/              иконки и ворота размера
.github/workflows/    сборка и выкладка на GitHub Pages при push в main
```

## Правила проекта

1. Ни одного факта без Q-номера Wikidata и ссылки на источник.
2. Цвета только через токены. Прямых `#hex` в компонентах нет.
3. Перед `git push` — зелёный `npm run check`.
4. Бюджеты: первая загрузка ≤ 1,5 МБ JS, снимок границ ≤ 250 КБ, музыка ≤ 12 МБ.
